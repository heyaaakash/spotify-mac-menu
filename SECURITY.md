# Security reports

Do not put access/refresh tokens, authorization codes, callback URLs, account information, private playlists, or exploit details in a public issue.

If **Security → Report a vulnerability** is available on this repository, use GitHub’s private reporting route. Otherwise, open an issue with only a non-sensitive request for a private contact method; wait for the maintainer’s response before sharing details. Private vulnerability reporting has not been confirmed enabled for this currently private repository.

The maintained source is `main`, currently version 1.3.0. There are no published SpotMenu releases yet. For ordinary bugs, use the bug-report template and redact screenshots and logs.
